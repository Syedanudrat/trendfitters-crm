# TrendFitters CRM — AWS Infrastructure

AWS infrastructure implementation for the TrendFitters Mens' Wear CRM platform.

## Project Objective

Build a secure, scalable, highly available, and cost-conscious CRM platform on AWS for the TrendFitters sales team.

## Technology Stack

- Terraform
- Amazon VPC
- Amazon ECR
- Amazon RDS
- Amazon EKS
- Application Load Balancer
- IAM
- AWS Secrets Manager
- Amazon CloudWatch
- Kubernetes
- GitHub

## Implementation Phases

1. Project and GitHub setup
2. Terraform backend
3. VPC and networking
4. Security
5. VPC endpoints
6. Amazon ECR
7. Amazon RDS
8. Amazon EKS
9. Application Load Balancer
10. CRM application
11. Kubernetes deployment
12. Secrets and IAM
13. CI/CD
14. Monitoring
15. Production hardening

## Environment

- Environment: dev
- AWS Region: ap-south-1
